# 📖 About

This repository showcases hands-on SOC projects built in a home lab environment to simulate real-world cyber attacks.

Each project follows the workflow used by Security Operations Center (SOC) analysts:

- Detection Engineering
- Alert Triage
- Event Correlation
- Threat Investigation
- Root Cause Analysis
- MITRE ATT&CK Mapping
- Investigation Documentation

The objective of this repository is to strengthen practical SOC analyst skills through realistic attack simulations and professional investigation reporting.
