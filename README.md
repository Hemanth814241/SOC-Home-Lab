# 🛡️ SOC Home Lab

Welcome to my SOC Home Lab portfolio.

This repository showcases hands-on Security Operations Center (SOC) projects built in a home lab environment. Each project simulates real-world attack scenarios, develops detection logic, investigates security events, and documents the complete incident response process.

## 🎯 Objectives

- Build practical SOC analyst skills
- Simulate real-world cyber attacks
- Detect threats using Splunk SIEM
- Investigate security alerts
- Practice incident response workflows
- Map attacks to the MITRE ATT&CK Framework
- Document investigations professionally

## 🛠️ Lab Environment

- Windows 10 Virtual Machine
- Kali Linux Attacker Machine
- Splunk Enterprise
- Splunk Universal Forwarder
- Sysmon
- Windows Security Event Logs
- Git & GitHub

## 📂 Projects

### 🛡️ Project 01 – RDP Brute Force Detection & Investigation
**Status:** ✅ Completed

**Description:**
Simulated an RDP brute-force attack from a Kali Linux attacker machine against a Windows 10 victim. Developed a custom Splunk detection rule, investigated the generated alert, validated the absence of successful authentication, and documented the complete incident response process.

**Skills:**
- Splunk Enterprise
- Windows Event Logs
- Event ID 4625 Analysis
- SPL Query Development
- Incident Investigation
- MITRE ATT&CK Mapping
